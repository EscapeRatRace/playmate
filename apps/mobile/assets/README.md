# Mobile App Assets

This folder holds the generated, brand-neutral launch artwork for the Playmate app:

- `icon.png` — Home screen icon (1024×1024 recommended)
- `adaptive-icon.png` — Android adaptive icon foreground layer
- `splash.png` — Launch / splash screen
- `favicon.png` — For web preview builds

The icon uses a sports-court mark and ball. Review the final branding and store icon
with the product owner before the first public Play Store release.
